Privacy policy

Plain language, no legal boilerplate padding. Describes exactly what this codebase does, not a generic template.

What is collected

Creating an account collects your email address, a password (never stored in plain text, see below), and an optional display name. Using the product creates verification history: the protocol text you paste or upload, and the full result Verilab computed for it (status, every violation found, the numbers involved, and any generated robot code). A session cookie identifies you as signed in between requests.

What's encrypted and never shown again

Your Anthropic API key is encrypted before it is written to disk. Once saved, the application never displays it again in plain text, a masked version like sk-ant**********XwAA is shown instead. The key is decrypted only in server memory, for only as long as it takes to make your own verification request, and is never written to a log file.

What is never done

  • Your API key is never logged, in application logs, error messages, or anywhere else.
  • Your API key is never shared with, or visible to, any other account.
  • Your API key is never used for anything except powering your own verification requests. It is not used for the marketing page's example mockups, which are precomputed separately and never call a signed-in user's key.
  • Your password is never stored or logged in plain text, only its PBKDF2 hash.

Third parties

When you verify raw protocol text, that text is sent to Anthropic's API using your own stored key, to turn it into structured steps. That request is between your account and Anthropic, on your own key and your own usage, the same as if you called their API directly. No other third party receives your protocol text, your account data, or your API key.

Analytics

The public marketing page uses basic, privacy-respecting page-view analytics to understand traffic. It does not run on any signed-in page (Dashboard, Stored Protocols, Settings), so your verification activity is never part of that data.

Deleting your account

Settings has a delete account action. It permanently removes your account row, your encrypted API key, and every protocol you've verified. This happens immediately and cannot be undone.

To delete your account: sign in, go to Settings, and use the delete account action at the bottom of the page.
