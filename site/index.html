What it checks

Four checks, each deterministic, each with a real reason it exists.

Volume overflow

Checks cumulative liquid added to a well, across every step, against that well's real container capacity.

Step ordering

Checks that nothing is drawn from, incubated, or measured before an earlier step has actually filled it.

Tip contamination

Runs the generated code for real, with aspirate and drop_tip instrumented, and flags a tip that touches two reagents before being replaced.

Verified code generation

Only generates real Opentrons Python for a plan that has already passed every check above, nothing is generated first and checked after.
